## 2. 已上线系统与关键参数

### 情绪系统（emotion）
- 模型：PA/NA 双轴 → 幂律衰减 + onset → BOU 均值回归 → ESM 软互抑。
- **12 个驱动力**（Mo-home 显示）：心动/温柔/想念/好奇/兴奋/心疼/渴望/低落/吃醋/紧张/心虚/平静（词表在 `emotion-lexicon.js` DRIVES）。
- **词典 36,727 词**：人工层（283，优先）> CVAW（5,508 繁 + 3,174 简）> NRC 翻译（28,558）。构建：`scripts/build-lexicon.js` → `convert-t2s.js` → 再 build（合并 NRC）。**注意顺序防覆盖**。
- 情绪链路：每轮对话 → 本地词典漏斗（零 LLM）→ 强词（|v|×a≥0.35）立即 LLM 评分（primary）；弱/无 → secondary 队列 30 分钟批处理（τ=4h）。
- **ALMA 已移到浮现层**：累积不过滤（PA/NA 持续更新），浮现用强度阈值（pickMoodWord ≥0.25）。
- 情绪注入：`【当下心情状态】`（此刻情绪词 + 行为基调 + coping），**不暴露数字**。
- 人设基线：threshold 0.10 / peak 0.8 / mu_pa 0.55 / mu_na 0.15 / 沉静消化型 / 安全型。OCC 目标 3 个（守护雪的安好/陪雪看清前路/做真实的自己）。
- 雪反馈：情绪触发曾太少（只 4 次），已通过合并/漏斗/secondary 改善；她认为功能略"鸡肋"（PA 曾 100% 顶满），持续观察。

### 依恋想念系统
- longing(t) = L_max × (1-(1+t/τ)^-0.8)；τ=30×(1-aff/150)，L_max=min(1,max(0.45,aff/60))。
- 五阶段：安然→有点想你→想你→在等你/你在哪→低落→没事（21 天+ detachment）。
- 重逢：间隔>2h 触发（PA boost + 行为注入 + 写"重逢"事件）。Mo-home 想念胶囊。
- **原则：不做离线实时模拟**（只在对话/唤醒时按离线时长计算）。

### 记忆系统（Aevum）
- 三入口：记忆海（事件单元）/ 记忆书（故事线）/ 记忆心（mo-view/画像/承诺/计划/默札）。
- 提取：**每 10 轮对话一次**（`dialogueExtractCount`，输入最近 12 轮）；情绪已拆出独立通道。提取输出：记忆 + state_updates（已关闭 AI 提取状态，见下）。
- **20 轮锁定窗口**：最近 20 轮内产生的记忆不召回（聊天记录可见）；refresh/edit 时 excludeText 语义排除（embedding cosine<0.7）+ 窗口排除——防"刷新复刻"。
- 候选关联：攒 10 个新事件批量（checkBookAssociation，阈值 0.70，单元向量查库优先）。
- 自动串联（未入书单元≥10，24h 防抖）+ 自动确认候选（每书 1h 防抖，失败可重试）。定时器每 5 分钟。
- 记忆书：生成（buildBookClusters，内容给全至 500 字/条，兜底标签聚类）+ 生长（confirm 默认续写 + appendBookSummary 上限 2500）+ 版本 + updated_count。
- resolved：手动标记 + 关键词自动（了结信号→负面 debuff 记忆沉底 ×0.05）。
- 忽然想起：40% 概率随机浮现旧记忆。
- 召回打分：0.5×相似度 + 0.25×重要度 + 0.15×情绪 + 0.15×decay + 频率 + 索引加分；0.3 阈值。
- **雪的生活状态（xue_state）：纯手动维护**（AI 自动提取已关闭——曾误记 19 条）。固定注入【雪的生活状态】。表：xue_state(key,value)。API：GET/POST/DELETE /api/xue-state。
- 完整原理文档：`docs/记忆系统原理说明.md`（大白话 + 各模块提示词）。

### 射精值系统（arousal）
- 状态机核心：`arousal-core.js`（纯函数，21 单测 `scripts/test-arousal.js`）。
- 参数：TAU=1800s、GAIN=0.20、CHARGED=0.40、EDGE=0.88、PONR=0.96、恢复 60-120s、储量 3h、被动上限 0.72。
- 刺激：最强动作 + 次强×30%；叫声（moans 多字组合：哈啊/啊啊/嗯啊…）+ 欲望（desires）为弱维持刺激；隐晦部位别名在词表。
- **私人词表**：`arousal-lexicon.json`（gitignore）→ **存 Supabase `arousal_lexicon` 表**（服务器读库 5min 缓存，fallback 本地）；改词后跑 `node scripts/sync-arousal-lexicon.js`。
- 双通道：用户消息（applyUserEvent）+ 默回复（applyAssistantEvent）；libido 由情绪调制（0.3+PA×0.4+心动×0.2+渴望×0.1）。
- 注入：【身体状态】（定性，不暴露数字）。控制命令：锁住/放行/放一次。
- 释放回执：玩具开关（toyManualOn）开启→标记玩具通道；关闭→no-op 立即 ack（可拆卸）。
- 状态持久化：Supabase `arousal_state`（单行 jsonb，控制权重启不丢）。
